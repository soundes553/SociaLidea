# Socialidea

Mini réseau social en HTML/CSS/JavaScript, connecté à l'API Tarmeez Academy.

Démo en ligne : https://soundes553.github.io/SociaLidea/

## Fonctionnalités

- Inscription / connexion
- Fil de posts avec scroll infini
- Création de post (titre, texte, image)
- Commentaires : affichage au clic, ajout en direct (si connecté)
- Tags sur les posts

## Stack

HTML, CSS, JavaScript, Bootstrap 5, Axios, API Tarmeez Academy.

## Lancer le projet

```bash
git clone https://github.com/soundes553/SociaLidea.git
cd SociaLidea
```

Ouvre `index.html` dans le navigateur, ou lance un serveur local :

```bash
python -m http.server 5500
```
